# DuoNerds Homepage

This repository contains the DuoNerds Game-Tech Studio website from `D:\\dev2`.

## Local development

```powershell
pnpm install
pnpm dev
```

Build and validate with:

```powershell
pnpm run build
pnpm run typecheck
pnpm test
```

The site covers Metin2 systems, Palworld mods, Minecraft plugins, web tools, services, a shop, project planning, and bilingual DE/EN content.
